## 14:25 修复 BasePage 滑入动画不生效
- 根因1：构造器把页面设为 Visibility.Collapsed -> 折叠元素不参与布局，ActualWidth=0 -> ThicknessAnimation From/To 都是 0，等于无动画
- 根因2：用 Margin 做位移动画会反复触发布局，性能差且受父容器布局影响
- 修复：改 TranslateTransform.X 位移动画 + Opacity 淡入；AnimateIn 中先置 Visible 并 UpdateLayout() 取真实宽度，加屏幕半宽兜底
- FillBehavior.Stop + 基准值设为终点，避免动画结束残留与跳变

## 15:20 修复 AnimateOut 后白屏（根因=分层错误，不是动画代码）
- 现象：点下一步触发 AnimateOut 后整屏变白（只剩 MainWindow 白底）
- 根因：PageAnimations 里 sb.Begin(page) 作用于整个 Page，而蓝色底(FontColor4Brush #27ADF5) + emoji 背景就画在 LoginPage 内部 -> 整页 Opacity 1->0 + Margin 位移把背景一起带走
- 修法：背景上移到 MainWindow 窗口外壳层（Border 蓝底 + Grid.ImageBrush emoji，Frame 嵌套其内），LoginPage 只保留内容层
- 顺带修出另一个真 bug：原代码用 page.WindowWidth 当位移距离。Page.WindowWidth 只在 NavigationWindow 宿主有值，普通 Window+Frame 下是 NaN -> Margin 的 From/To 非法 -> 滑动一直失效，之前"滑入效果没了"很大程度是这个原因。改为 GetOffset()：ActualWidth > Width > 屏幕半宽兜底
- 修正时序：Visibility=Visible + UpdateLayout() 提到 sb.Begin 之前（原版在 Begin 之后，且构造器里 Collapsed 时 ActualWidth=0）
- LoginPage.Button_Click 从 void 改为 async void + await，修正时序（否则 CS0266/CS0407 或 CS4014）
- 当前动画实现为用户恢复的教程原版三件套：Animation/PageAnimation.cs + PageAnimations.cs + StoryboardHelpers.cs；BasePage 为教程原版（SlideSeconds=0.8、构造器设 Collapsed）
- 代价备忘：背景现在属于窗口外壳，所有页面共享；若某页想要自己的背景，需在页面内自带并单独处理动画目标
